# 原品数量与自定义货号功能说明

## 功能说明

从此版本开始,快麦建货号功能支持两个增强特性:

1. **原品数量字段**: 在 Excel 表格中添加"原品数量"列,控制新建套装时每个组件的数量
2. **自定义货号支持**: 在"商品SKU货号"列填写自定义货号,系统会使用该货号并进行查重校验

## 使用方式

### 1. Excel 表格配置

在导入的 Excel 表格中可添加以下两列:

| 品牌 | 产品原品编码 | 产品名 | 容量 | 贴纸编码 | 配件 | **原品数量** | **商品SKU货号** |
|------|------------|--------|------|---------|------|------------|----------------|
| WKAU | YP-CWJ01-04 | 除味剂 | 60ml | 0957069011 | 自粘袋 说明书 | **2** | |
| WKAU | YP-CDJJS01-03 | 穿戴甲胶水 | 30ml | 09590707 | 说明书 白色按压喷头 | **3** | **CUSTOM-SKU-001** |

### 2. 原品数量字段

**默认行为**:
- **如果表格中有"原品数量"列**: 使用该列的数值作为套装中每个组件的数量
- **如果表格中没有"原品数量"列**: 默认使用数量 1(与之前版本行为一致)
- **如果"原品数量"列的值无效**(如空白、非数字、0 或负数): 默认使用数量 1

**效果展示**:

#### 数量为 2 时:
```
套装标题: WKAU除味剂60ml*2+自粘袋*2+说明书*2
组合比例: 产品原品×2 + 自粘袋×2 + 说明书×2 + 贴纸×2
```

#### 数量为 3 时:
```
套装标题: WKAU穿戴甲胶水30ml*3+说明书*3+白色按压喷头*3
组合比例: 产品原品×3 + 说明书×3 + 白色按压喷头×3 + 贴纸×3
```

#### 未填写数量(默认为 1):
```
套装标题: WKAU除味剂60ml*1+自粘袋*1+说明书*1
组合比例: 产品原品×1 + 自粘袋×1 + 说明书×1 + 贴纸×1
```

### 3. 自定义货号支持

**默认行为**:
- **如果"商品SKU货号"列有值**: 直接使用该货号作为套装货号,不会自动生成
- **如果"商品SKU货号"列为空**: 按规则自动生成货号: `{前缀}-{品牌编码}-{产品名首字母}-{贴纸编码}`

**查重校验**:
- 无论是自定义货号还是自动生成的货号,预演阶段都会去 ERP 系统查重
- 如果货号已存在,会标记为 `preview_blocked`,阻止导入,提示"ERP 中已存在套装货号，不允许导入"

**使用场景**:
- 需要使用特定的货号命名规则
- 批量导入时保持与已有系统的货号一致性
- 对货号格式有特殊要求

### 4. 组合使用

两个功能可以同时使用:

```excel
品牌    产品原品编码     产品名        容量   贴纸编码      配件              原品数量   商品SKU货号
WKAU    YP-CWJ01-04     除味剂        60ml   0957069011    自粘袋 说明书      2         MY-CUSTOM-SKU-001
```

**效果**:
- 套装货号: `MY-CUSTOM-SKU-001`
- 套装标题: `WKAU除味剂60ml*2+自粘袋*2+说明书*2`
- 组合比例: 每个组件数量为 2
- 查重校验: 会检查 `MY-CUSTOM-SKU-001` 是否已存在

## 技术实现

### 修改的文件

1. **类型定义** (`src/shared/types/sku-import.ts`)
   - `SkuImportPreviewRow` 接口添加 `quantity: number` 字段

2. **数据解析** (`src/tools/sku-import/domain.ts`)
   - `normalizeImportRowValues` 函数读取并解析"原品数量"列
   - 数值校验: 自动处理无效值(转为 1)
   - 读取"商品SKU货号"列作为 `existingSkuCode`

3. **预览生成** (`src/tools/sku-import/preview.ts`)
   - `proposedSkuCode` 优先使用 `existingSkuCode`,否则自动生成
   - `previewRowBase` 函数将 `quantity` 传递给 `buildBundleTitle`
   - 预览时显示正确的套装标题
   - 无论哪种货号都会进行 ERP 查重校验

4. **执行创建** (`src/tools/sku-import/executor.ts`)
   - 创建套装时,为产品原品、配件和贴纸的 `ratio` 字段设置正确的数量值

### 数据流

```
Excel 读取
    ↓
"商品SKU货号"列 (existingSkuCode) → 如有值则使用,否则自动生成 proposedSkuCode
"原品数量"列     (quantity)        → 解析数值 (默认 1, 最小 1)
    ↓
预览阶段
    ↓
ERP 查重校验 (proposedSkuCode)
    ↓
buildBundleTitle 生成套装标题 (产品*N+配件*N)
    ↓
执行创建
    ↓
createPureSuite 创建套装 (货号 + 每个组件的 ratio 为 N)
```

- ✅ **类型安全**: 所有修改都通过了 TypeScript 类型检查
- ✅ **测试覆盖**: 添加了完整的单元测试,验证各种场景

新增测试验证以下场景:
1. ✅ 原品数量有值时正确解析和应用
2. ✅ 原品数量为空时默认为 1
3. ✅ 原品数量为无效值时默认为 1

## 注意事项

### 原品数量
1. "原品数量"列必须是整数,小数会被向下取整
2. 数量最小为 1,即使填写 0 或负数也会被自动调整为 1
3. 数量会同时应用于: 产品原品、贴纸和所有配件
4. 套装标题和 ERP 中实际创建的组合商品都会使用指定的数量

### 商品SKU货号
1. 如果填写了自定义货号,系统会直接使用,不会按规则生成
2. 自定义货号也会进行 ERP 查重校验,已存在则阻断
3. 自定义货号应符合 ERP 系统的货号规范
4. 建议自定义货号保持一致的命名规则,便于管理

## 示例

### 示例 1: 仅使用原品数量

```excel
品牌    产品原品编码     产品名        容量   贴纸编码      配件              原品数量
WKAU    YP-CWJ01-04     除味剂        60ml   0957069011    自粘袋 说明书      2
```

**结果**:
- 货号: `69-39-CWJ-0957069011` (自动生成)
- 标题: `WKAU除味剂60ml*2+自粘袋*2+说明书*2`

### 示例 2: 仅使用自定义货号

```excel
品牌    产品原品编码     产品名        容量   贴纸编码      配件              商品SKU货号
WKAU    YP-CDJJS01-03   穿戴甲胶水    30ml   09590707      说明书            CUSTOM-001
```

**结果**:
- 货号: `CUSTOM-001` (使用自定义)
- 标题: `WKAU穿戴甲胶水30ml*1+说明书*1`

### 示例 3: 组合使用

```excel
品牌    产品原品编码     产品名        容量   贴纸编码      配件              原品数量   商品SKU货号
WKAU    YP-BYPM01-02    布艺泡沫      100ml  09590808      自粘袋            3         BYPM-SPECIAL-001
```

**结果**:
- 货号: `BYPM-SPECIAL-001` (使用自定义)
- 标题: `WKAU布艺泡沫100ml*3+自粘袋*3`
- 组合: 每个组件×3
